# 用户手册

> 适用版本：**v0.4.0**（Android / Linux / Windows）｜维护：AI ｜ 最后更新：2026-10-28
>
> WorthTrack 是**纯本地**记账 + A 股/场内基金投资跟踪应用：没有账号、没有云端、没有遥测。
> 所有数据只存在你这台设备上，因此**备份要你自己做**（见第 9 节）。

---

## 1. 安装与首次启动

| 平台 | 安装方式 |
|---|---|
| Android | 从 [Releases](https://github.com/zeek-zhao/WorthTrack/releases) 下载 `app-release.apk` 安装（首次需允许「安装未知来源应用」） |
| Linux | 下载 `worthtrack-linux-x64.tar.gz` 解压后运行目录内的 `worthtrack` |
| Windows | 源码构建（`flutter build windows`），暂不提供预编译包 |

**升级**：直接装新 APK 覆盖即可，账目数据保留（数据在应用私有目录，与安装包无关）。

首次启动是空的，先做两件事：

1. **建账户**：资产页 → 右下角 `+` → 填名称、类型、当前余额（信用卡可填负数）
2. （可选）**开 PIN 锁**：设置 → 启动 PIN 锁 → 设 6 位数字

## 2. 记一笔

明细页右下角 `+`，三种类型：

| 类型 | 影响 | 说明 |
|---|---|---|
| 支出 | 账户余额减少 | 可挂分类 |
| 收入 | 账户余额增加 | 可挂分类 |
| 转账 | 转出减少、转入增加 | 必须选两个不同账户；**不计入收支统计** |

- 金额输入「元」，内部按「分」精确存储，不会出现 0.1+0.2 的浮点误差
- 日期时间可改，补记以前的账直接改日期即可

## 3. 明细页：查、改、删

- 流水按**日**分组，每日显示合计
- 顶部筛选：关键词（备注/分类名/账户名）、类型、账户、分类、时间区间，可组合
- **点一行**进入编辑；**长按**出删除菜单
- 删除会**自动回滚账户余额**，不会留下「钱凭空消失」
- 编辑等价于「先撤销原来那笔，再记新的一笔」，跨账户改也不会算错

## 4. 账户与分类

**账户**（资产页）：现金 / 储蓄卡 / 信用卡 / 投资账户。余额随时可改（用于对账）；不再用的账户用「归档」，流水保留、列表里隐藏。

**分类**（记一笔时可选）：内置 12 个常用分类，可自己加；支持**两级**（如「餐饮 → 外卖」）。归档父分类会连带归档子分类。

## 5. 报表与预算

- 报表页：本月/本年的支出、收入、结余；分类占比饼图；逐月趋势折线
- 预算：按「分类 + 月份」设额度，报表页会显示消耗进度；**超支会出红色横幅**
- 口径提醒：**转账不计入收支**；信用卡消费按支出计

## 6. 周期账单

适合房租、订阅、工资这类固定账单。建规则时选频率（每天/每周/每月/每年）、金额、起始日。

- 应用**启动时**自动补齐漏掉的期数（比如三个月没打开，会补生成三期并扣款）
- 同一期不会重复生成（幂等）
- 超过结束日期后规则自动停用

## 7. 投资跟踪（A 股 + 场内基金）

投资页 → `+` 添加持仓：市场（沪/深）、6 位代码、名称、份额、成本单价。

- **行情**：点右上角「刷新行情」从腾讯财经拉现价（公开接口，无需 key）。**不会自动刷新**，由你决定何时拉
- **价格时间**：持仓行副标题显示「价格更新 10-27 16:14」；从未拿到价格显示「待录价」
- **手动改价**：编辑持仓可填现价，行情拿不到时用它兜底
- **停牌 / 代码不存在 / 断网**：一律**沿用上一次的缓存价**，市值不会被清零；断网时依然能看盈亏
- **盈亏**：`市值 = 份额 × 现价`，`盈亏 = 市值 − 份额 × 成本价`，红涨绿跌（A 股习惯）
- 份额精度 0.01 份；场内基金 0.001 元报价四舍五入到分（每份误差 ≤ 0.5 分）

## 8. 资产总览与净资产

资产页顶部是**净资产**卡片与走势曲线。

> **口径（重要）**：净资产 = 现金类账户余额（现金 + 储蓄卡 + 信用卡）+ 全部持仓市值。
> **投资账户的余额不计入**——持仓市值已经代表这部分资产，两者同时计入会重复计算。
> 卡片下方会单独提示这笔余额，方便你核对。

- 没有现价的持仓不计入市值，卡片会提示「N 只持仓未录价」
- 走势曲线由当前净资产**反向回溯**（减去之后发生的收支、之后才建的仓位），
  历史各期持仓按**当前市值**折算，因此曲线只反映「仓位增减 + 收支变化」，不是历史真值

## 9. 备份与恢复（重要）

设置 → **备份与恢复**：

| 操作 | 说明 |
|---|---|
| 导出备份 | 生成一个 `.sqlite3` 文件（整库快照），选位置保存。可拷到电脑、网盘、聊天软件「文件传输助手」 |
| 从备份恢复 | 选文件 → **应用先体检**（是不是备份、版本是否匹配、表是否齐全）→ 二次确认（显示备份里有几个账户、几条流水）→ 覆盖 |

- 恢复是**整体替换**：当前账本里的全部数据会被备份内容换掉，且不可撤销 → **先导出一份再恢复**
- 恢复在单个事务里完成：中途出错会整体回滚，**当前数据一条不动**
- 换手机：旧机「导出备份」→ 传到新机 → 新机装应用 → 「从备份恢复」
- 备份**不含 PIN**（PIN 只和这台设备有关），恢复后在新机上按需重设

## 10. 导出 CSV（给 Excel 用）

设置 → **数据导出** → 导出流水（CSV）。

- 列顺序固定：`时间, 类型, 账户, 分类, 金额, 备注`
- UTF-8 **带 BOM**，Excel / WPS / Numbers 双击直开，中文不乱码
- 金额单位是「元」、两位小数，可直接求和
- 转账的账户列写成「转出 → 转入」
- 含逗号、引号、换行的备注会被正确加引号转义，不会把列拆散
- **CSV 只是副本，不能用来还原账本**；要还原请用「备份与恢复」

## 11. 常见问题

**Q：换手机/重装应用，数据会丢吗？**
会。数据只在本机应用私有目录，卸载即删。请养成定期「导出备份」的习惯。

**Q：忘记 PIN 了怎么办？**
锁屏页点「忘记 PIN？」→ 确认重置 → 直接进入。**重置只删 PIN 文件，账目一条不动**。

**Q：PIN 能加密数据吗？**
不能。PIN 只挡「别人拿到你手机随手翻看」。数据库文件本身不加密——这是 v1 明确的取舍。

**Q：行情为什么不自动更新？**
需求里明确「不做自动重试/轮询」：手动刷新更省电，也避免你在没网时被一串失败提示打扰。缓存价永远兜底。

**Q：净资产为什么比我账户余额加起来少？**
因为你可能有投资账户余额，它不计入净资产（持仓市值已经代表这部分资产）。卡片下方有提示。

**Q：Excel 打开 CSV 是乱码？**
正常情况不会（已带 BOM）。如果乱码，请用「数据 → 从文本/CSV 导入」并选 UTF-8；或用 WPS 打开。

**Q：能同步到云端/多设备吗？**
不能，v1 不做。要跨设备就用「导出备份 → 传文件 → 恢复」。

**Q：数据存在哪？**
Android：应用私有目录（`/data/data/<包名>/files/`，非 root 无法直接看到）。
所以「导出备份」是唯一便捷的取数方式。
