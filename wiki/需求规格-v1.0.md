# WorthTrack 需求规格（v1.0）

> 状态：**synced** ｜ 来源：Obsidian `40-项目/WorthTrack/01-需求规格.md` ｜ 同步日期：2026-10-25

## 1. 产品定位

个人本地化记账 + 理财应用：手工记账为核心，投资跟踪覆盖 A 股与场内基金，数据 100% 本地存储，不依赖任何账号与云服务。

## 2. 功能边界

### 2.1 记账核心（in scope）
- **交易记录**：支出/收入/转账，金额、时间、账户、分类、备注
- **多账户**：现金、银行卡、信用卡、投资账户；账户余额自动计算
- **分类**：可自定义收支分类（图标+名称），支持二级分类
- **周期账单**：按日/周/月周期自动生成记账（如房租、订阅）
- **月度预算**：按分类设预算，超支提示
- **报表**：月/年度收支汇总、分类占比（饼图）、趋势（折线）
- **搜索与筛选**：按时间/账户/分类/关键词过滤流水

### 2.2 投资跟踪（in scope，边界明确）
- **持仓管理**：股票/场内基金代码、名称、持有份额、成本价，手动建立
- **行情刷新**：仅 A 股 + 场内基金；数据源为新浪财经/腾讯财经公开接口（无 key）；接口层留 PriceProvider 抽象便于后续扩展
- **离线兜底**：每次成功拉取的价格落库；拉取失败用缓存价计算市值，UI 标注「价格更新时间」；支持手动改价
- **盈亏计算**：市值 = 份额 × 现价；盈亏 = 市值 − 份额 × 成本价；浮动盈亏百分比
- **资产总览**：现金/储蓄/投资市值汇总为净资产曲线

### 2.3 数据与安全（in scope）
- 一键备份：导出整个 .db 文件；恢复：选择 db 文件导入
- CSV 导出：交易流水（UTF-8 BOM，Excel 直开不乱码）
- 应用启动 PIN 锁（不加密数据库文件，依赖系统应用沙箱）

### 2.4 明确不做（v1.0）
- 港股/美股/场外基金行情
- 自动重试行情拉取（只有失败→缓存价，无重试状态机）
- 数据库加密（SQLCipher）、云同步、多端同步
- JSON 全量导出、宽屏双栏桌面布局、iOS/macOS
- 记账 OCR/导入第三方账单（后续版本可议）

## 3. 数据模型（概要）

| 表 | 内容 |
|---|---|
| accounts | 账户（类型、名称、初始余额） |
| transactions | 交易（类型、金额、账户、分类、时间、备注、关联周期账单） |
| categories | 分类（收支、父级、图标） |
| budgets | 预算（分类、周期、金额） |
| recurring_rules | 周期账单规则（频率、金额、模板） |
| positions | 持仓（代码、名称、份额、成本价、账户） |
| price_cache | 行情缓存（代码、价格、更新时间） |

**金额一律整数存储（分）**，避免浮点误差——碰钱计算的单测重点。

## 4. 非功能约束

| 维度 | 要求 |
|---|---|
| 平台 | Android 8.0+（APK）；Linux/Windows 桌面跑同款布局 |
| 语言 | 简体中文为主，国际化框架预留 |
| 性能 | 万级流水下列表滚动与报表渲染不卡顿 |
| 隐私 | 无任何遥测/上传；行情接口仅拉取公开报价 |
| 测试 | 见 [[项目计划与里程碑]] 质量门槛章节 |

## 5. 验收标准（v1.0 出口条件）

1. M1-M4 里程碑全部 issue 关闭
2. CI 全绿：format/analyze/test 通过，碰钱路径集成测试（约 10-12 条）通过
3. 真机手测清单逐项通过
4. GitHub Release 存在 v1.0.0，附签名 APK + Linux 包
5. 断网状态下：记账、报表、以缓存价查看投资盈亏全部可用
