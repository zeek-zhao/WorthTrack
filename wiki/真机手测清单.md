# 真机手测清单

> 用途：**每次发版前**在真机上逐项手测，全绿才允许打 tag。
> 维护：AI ｜ 最后更新：2026-10-28（v0.4.0 起启用）
>
> 自动化能覆盖的部分见 `docs/money-paths-coverage.md`（碰钱路径集成测试 13 条）；
> 本清单只测**自动化测不到**的东西：真实触屏、真实网络、真实系统行为。

## 0. 前置准备

- [ ] 测试机：Android 8.0+（建议再找一台 Android 13+ 验证存储权限行为）
- [ ] 安装包：CI 产出的**签名** `app-release.apk`（不是 debug 包）
- [ ] 旧版本 APK（验证「覆盖升级不丢数据」）
- [ ] 一个空账本 + 一份已知内容的备份文件
- [ ] 可选：飞行模式开关、另一台设备（验证备份迁移）

## 1. 安装与首启

- [ ] 全新安装能正常打开，不闪退、不白屏
- [ ] **覆盖升级**（先装旧版、记几笔、再装新版）：版本号变了，数据全在
- [ ] 首次启动无网络权限申请弹窗打扰（行情是可选动作）
- [ ] 空账本各页都有空态提示（明细/报表/资产/投资）
- [ ] 系统深色模式下文字可读、无白底黑字错位

## 2. 记账核心

- [ ] 建账户（现金/储蓄卡/信用卡各一个），余额显示正确
- [ ] 信用卡填负数余额，总资产正确抵减
- [ ] 记支出：余额减少、明细页出现该笔、日合计正确
- [ ] 记收入：余额增加
- [ ] 转账：两个账户余额同时变化，**总资产不变**，报表里不计入收支
- [ ] 编辑一笔（改金额、改账户、改类型）：余额都正确
- [ ] 删除一笔：余额回滚
- [ ] 金额输入边界：`0`、`0.01`、`9999999.99`、小数两位以上（应被处理成两位）
- [ ] 日期改到上个月：该笔落到上月，本月合计不含它
- [ ] 键盘弹出时表单不被遮挡，能滚到「保存」

## 3. 报表与预算

- [ ] 月/年切换，收支结余与手算一致
- [ ] 分类占比饼图颜色可区分，点扇区/图例有反馈（如无交互则忽略）
- [ ] 逐月趋势折线：数据不足 2 个月时显示空态而不是一个孤点
- [ ] 设预算 → 记一笔接近额度 → 进度条变化；超支后出红色横幅
- [ ] 跨月预算互不干扰（上月超支不影响本月）

## 4. 周期账单

- [ ] 建一条「每月 10 日」的规则
- [ ] 把系统日期改到下月 11 日再打开应用 → 自动补生成一期、余额扣减
- [ ] 重复打开应用不会重复生成
- [ ] 建一条已过结束日的规则 → 自动停用、不再生成
- [ ] 月末日期规则（1 月 31 日 → 2 月 28/29 日）不报错、不跳过月份

## 5. 投资跟踪

- [ ] 添加沪市股票（如 600519）与深市场内基金（如 159915），份额与成本正确
- [ ] 点「刷新行情」：有网时拿到现价，副标题显示「价格更新 MM-DD HH:mm」
- [ ] 盈亏颜色：涨红跌绿（A 股习惯）
- [ ] **飞行模式下刷新**：提示失败，但市值仍按缓存价显示，不被清零
- [ ] 手动改价后市值/盈亏立即更新
- [ ] 编辑持仓时市场/代码只读（避免唯一键语义混乱）
- [ ] 归档持仓：列表消失，历史统计不受影响
- [ ] 份额精度：填 0.01 份能保存并正确估值

## 6. 资产总览

- [ ] 净资产 = 现金类余额 + 持仓市值（**投资账户余额不计入**，卡片下方有提示）
- [ ] 有持仓未录价时提示「N 只持仓未录价」，市值不把无价持仓算成 0 亏损
- [ ] 走势曲线末点等于当前净资产
- [ ] 曲线数据不足 2 点时显示空态

## 7. 安全（PIN 锁）

- [ ] 设置 6 位 PIN → 杀进程重开 → 出现锁屏
- [ ] 输错 PIN：提示错误并清空重输，不锁死
- [ ] **从后台返回**（Home 键切走再回来）→ 重新上锁
- [ ] 关闭 PIN 需先验证当前 PIN
- [ ] 修改 PIN：验证旧 PIN → 设新 PIN → 用新 PIN 能解锁、旧 PIN 失效
- [ ] 「忘记 PIN？」重置：能直接进入，**账目一条不少**

## 8. 备份与恢复（v0.4.0 重点）

- [ ] 导出备份：系统「另存为」能选目录（含「下载」与自建目录），保存成功并提示大小
- [ ] 到文件管理器里能找到该 `.sqlite3` 文件，大小合理（KB 级）
- [ ] 取消保存：无成功提示，无残留文件
- [ ] 从备份恢复：先出**体检结果**（账户数/流水数/文件大小），再二次确认
- [ ] 点「取消」→ 数据不变
- [ ] 确认恢复 → 数据与备份一致（余额、流水条数、持仓、行情缓存价）
- [ ] **拿一个 txt/图片文件去恢复**：提示「不是 WorthTrack 的备份」，不给覆盖
- [ ] 恢复后继续记账、刷新行情都正常（连接没被搞坏）
- [ ] 跨设备：A 机导出 → 传到 B 机 → B 机恢复 → 数据一致

## 9. CSV 导出

- [ ] 导出流水 CSV：选目录保存成功，提示「已导出 N 条流水」
- [ ] 用 Excel/WPS 打开：**中文不乱码**、列顺序为 时间/类型/账户/分类/金额/备注
- [ ] 备注里含逗号与引号的记录没有被拆列
- [ ] 转账行的账户列显示「转出 → 转入」
- [ ] 金额可直接求和（数值列，不是文本）

## 10. 异常与边界

- [ ] 飞行模式下：记账、报表、预算、周期账单全部可用；投资盈亏按缓存价显示
- [ ] 切后台 5 分钟回来：数据不丢、不闪退、PIN 正常上锁
- [ ] 系统字体放到最大：文字不截断、按钮不被挤没
- [ ] 横竖屏切换（如允许）：布局不错乱
- [ ] 连续快速点击「保存」：不产生重复流水
- [ ] 低电量模式/省电模式：功能正常

## 11. 发版检查（打完 tag 之后）

- [ ] GitHub Actions 全绿（format / analyze / test / integration / release）
- [ ] Release 页面存在：`app-release.apk` + `worthtrack-linux-x64.tar.gz`
- [ ] APK 是**签名**包（不是 debug），体积与上版接近（异常增大说明误打包）
- [ ] Release 说明与 `docs/release-notes-template.md` 结构一致，写明升级方式与已知问题
- [ ] 从 Release 下载安装包，能在干净设备上装成功（不只是本地包）
