## 一句话

**第一版正式版**——记账、报表、预算、周期账单、A 股/场内基金持仓、净资产曲线、PIN 锁、
整库备份恢复、CSV 导出，全部就位；数据 100% 留在本机。

- **与 v0.4.0 代码完全一致**（`git diff v0.4.0..v1.0.0 -- lib test pubspec.yaml` 为空）
- 因此产物与 v0.4.0 **二进制等价**，功能无新增、无修复
- 版本号从 0.x 升到 1.0.0，含义是「M1–M4 四个里程碑全部关闭，能力集合封板」，不是「有破坏性变更」
- **数据兼容**：`schemaVersion` 仍为 1，从 v0.1–v0.4 直升，无需迁移

## 升级方式

| 平台 | 步骤 |
|---|---|
| Android | 下载 `app-release.apk` 覆盖安装，**数据保留** |
| Linux | 下载 `worthtrack-linux-x64.tar.gz` 解压替换可执行文件 |

## 已知问题 / 取舍

- **PIN 不加密数据库**：只挡「别人拿到手机随手翻看」；数据库文件本身未加密
- **行情不自动刷新**：手动点「刷新行情」；停牌/断网/代码不存在时一律沿用缓存价，市值不会被清零
- **净资产口径**：投资账户余额不计入（持仓市值已代表这部分资产），卡片下方有单独提示
- **历史净值曲线**：由当前净资产反向回溯，历史各期持仓按当前市值折算，只反映仓位增减与收支变化
- **不做云同步**：跨设备靠「导出备份 → 传文件 → 恢复」
- **CSV 不能还原账本**：它只是一份给 Excel 用的副本，还原请用备份
- **行情接口为未公开免费接口**：高频轮询可能被限流，「实时」有天花板
