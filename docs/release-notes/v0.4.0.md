# WorthTrack v0.4.0

> 发布日期：2026-10-28 ｜ 里程碑：M4 备份与打磨（4/4 完成）

## 一句话

**账本终于可以备份和带走了**——一键导出整库、换手机恢复、流水导成 Excel 直开的 CSV；
顺手把碰钱路径的集成测试补到 13 条。

## 新增

### 1. 账本一键备份与恢复（设置 → 备份与恢复）

- **导出备份**：把整个账本存成一个 `.sqlite3` 文件，位置你自己选（手机「下载」目录、网盘同步目录都行）
- **从备份恢复**：选文件后应用**先体检**——是不是备份、版本是否匹配、表是否齐全，
  再弹二次确认（显示备份里有几个账户、几条流水、几只持仓），确认后才覆盖
- 恢复在**单个事务**里完成：中途出错整体回滚，当前数据一条不动
- 换手机流程：旧机导出 → 传文件 → 新机装应用 → 恢复

### 2. 流水导出 CSV（设置 → 数据导出）

- 列顺序：`时间, 类型, 账户, 分类, 金额, 备注`
- UTF-8 **带 BOM**，Excel / WPS / Numbers 双击直开，中文不乱码
- 备注里的逗号、引号、换行会被正确转义，不会把列拆散
- 转账的账户列写成「转出 → 转入」

| 平台 | 步骤 |
|---|---|
| Android | 下载 `app-release.apk` 覆盖安装，**数据保留** |

## 已知问题 / 取舍

- **PIN 不加密数据库**：只挡「别人拿到手机随手翻看」；数据库文件本身未加密
- **行情不自动刷新**：手动点「刷新行情」；停牌/断网/代码不存在时一律沿用缓存价，市值不会被清零
- **净资产口径**：投资账户余额不计入（持仓市值已代表这部分资产），卡片下方有单独提示
- **历史净值曲线**：由当前净资产反向回溯，历史各期持仓按当前市值折算，只反映仓位增减与收支变化
- **不做云同步**：跨设备靠「导出备份 → 传文件 → 恢复」
- **CSV 不能还原账本**：它只是一份给 Excel 用的副本，还原请用备份
