# 碰钱路径集成测试覆盖矩阵

> 用途：issue #21「对照 wiki 验收标准逐条核对全覆盖」的落地凭证。
> 唯一执行文件：`integration_test/money_paths_test.dart`（**只允许这一个文件**，原因见
> `docs/troubleshooting.md` 1.5）。
> 每次新增碰钱逻辑时，先在这张表里找到对应场景再动代码；找不到就说明表格该更新。

## 1. 执行方式

| 场景 | 命令 |
|---|---|
| CI（自动） | `.github/workflows/ci.yml` 的 quality job，`xvfb-run -a flutter test integration_test` |
| 本地 WSL | 需先装 Linux 桌面工具链（`clang cmake ninja-build pkg-config libgtk-3-dev xvfb`），再 `xvfb-run -a bash scripts/wt_flutter.sh flutter test integration_test` |

集成测试跑的是**真 Drift + 真 SQLite**（内存库或临时文件），只把外部世界替换掉：
行情用 `MockClient` 喂构造好的 GBK 响应，文件选择器用假实现。

## 2. 覆盖矩阵（13 条）

| # | 用例 | 覆盖的碰钱逻辑 | 关键断言 |
|---|---|---|---|
| 1 | 建账户 → 记支出 → 余额变化正确 | 交易写入与余额调整同事务 | 余额 100000−2580=97420；流水金额可查回 |
| 2 | 两账户转账 → 双方余额正确 | 转账双边记账 | 转出 5000−1500、转入 +1500；总资产守恒 5000 |
| 3 | 删除交易 → 余额回滚正确 | 删除时冲销原影响（幂等） | 删除收入后余额 = −38000；流水只剩 1 条 |
| 4 | 周期账单连漏三期 → 补生成且幂等 | `catchUp` 补生成 + 余额扣减 | 生成 3 条、余额减 4500、二次调用返回 0、日期都落在 10 日 |
| 5 | 预算消耗：当月计入、跨月不计入、超支判定 | 预算口径与月度边界（左闭右开） | 九月/十一月不计入十月；超支时 `remainingMinor` 为负 |
| 6 | 刷新行情 → 缓存价落库、市值与盈亏正确 | 行情解析 → price_cache → 估值流 | 现价 1355.90 落库、市值 20338500、缓存时间取行情时间 |
| 7 | 刷新遇停牌 → 沿用缓存价 | 停牌不覆盖缓存（#15 兜底） | `suspended=1`、市值仍 25500000 |
| 8 | 净资产：支出降低、转账不变、投资市值计入 | 净资产口径 + 历史回溯 | 转账前后净资产不变；曲线末点 = 当前净资产 |
| 9 | 忘记 PIN 重置不清数据 | PIN 与账目解耦（结构性保证） | 删 PIN 文件后余额 487655、流水仍 1 条 |
| 10 | 导出备份 → 清空 → 恢复 | 导出快照 + 单事务整体替换 | 余额/流水/持仓/缓存价逐项一致 |
| 11 | 导出流水 CSV | 分转元、名称联表、BOM 与转义 | BOM 三字节；列顺序；`"午饭,加饮料"` 不被拆列 |
| 12 | 编辑交易：改金额 + 换账户 + 改类型 | 先冲销旧影响再应用新影响（最容易算错） | 工资卡回到 1000000、零钱 97000→103000、流水仍 1 条 |
| 13 | 断网刷新行情 → 缓存价不动、记账照常 | 整批失败不覆盖缓存（验收标准 5） | `failed=1`、市值 25500000、断网时记账仍正确 |

## 3. 与 wiki 验收标准的对应

`wiki/需求规格-v1.0.md` §5「验收标准（v1.0 出口条件）」：

| 验收标准 | 对应保障 |
|---|---|

## 4. 刻意不放进集成测试的部分

| 内容 | 理由 | 替代覆盖 |
|---|---|---|
| 页面布局、弹窗、表单校验 | 与钱无关，跑一次集成测试要几十秒，不值得 | `test/ui/*_test.dart`（假仓储） |
| 网络真实连通性 | 依赖外网，会随机红 | `MockClient` + `test/data/tencent_price_provider_test.dart` 的 fixture |
| 系统文件对话框 | 无头环境弹不出来，会挂住 | `FileSavePicker` 假实现 |
| schema 迁移 | v1 至今零迁移（`schemaVersion` 恒为 1） | 待第一次 `onUpgrade` 时补迁移测试 |
